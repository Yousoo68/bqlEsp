📌 01. 포토샵 기본기 CORE
Pixel 비트맵 최소 단위  |  해상도 화면 72ppi · 인쇄 300ppi
🎯 비트맵 vs 벡터비트맵: 픽셀집합 (jpg/png) 확대 깨짐
벡터: 수학적 함수 (ai/eps) 확대 무손실
🖥️ Screen vs PrintScreen: RGB, 72ppi / Print: CMYK, 300ppi, mm
🌈 RGB vs CMYKRGB(빛, 가산혼합) 모니터용 / CMYK(잉크, 감산) 인쇄용
💡 레이어 살아있는 원본은 반드시 PSD로 저장! Ctrl+S 습관
⚙️ 인터페이스 핵심: Tab 패널 숨기기, F 화면모드, D 전경/배경 기본(흑백), X 색 교체
📏 이미지/캔버스 사이즈 Ctrl+Alt+I / Ctrl+Alt+C · Resample Preserve Details 확대 선명
🧩 레이어 기초: Ctrl+J 복사, 배경레이어 잠금해제 더블클릭, History 패널 스냅샷
✂️ 02. 선택 · 이동 · 변형 TOOL
V 이동 툴: Alt+드래그 복제이동, Shift+방향키 10px 이동, 자동선택 가능
Ctrl+T 자유변형: 코너 비율유지, Alt+드래그 중심기준, 우클릭 왜곡/뒤집기/뒤틀기
선택툴: M 정형(Feather 경계흐림) · L 올가미(다각형/자석) · W 개체선택/AI, 빠른선택, 마술봉(Tolerance)
Ctrl+A 전체선택 Ctrl+D 해제 Ctrl+Shift+I 반전 Shift+F6 Feather Q 퀵마스크
C 크롭툴: 수평맞춤, Content-Aware 빈공간 자동채움
✨ 배경 단색 > 마술봉 선택 후 Ctrl+Shift+I 반전 = 오브젝트 완벽선택
🖌️ 03. 복원·리터칭 & 드로잉 HEAL+BRUSH
🎭 선명/흐림(R): 블러(흐림) · 샤픈(선명) · 스머지(뭉개기)
☀️ 닷지/번(O): 닷지(밝게) / 번(어둡게) / 스펀지(채도) Range: Shadow/Mid/Highlight
🩹 복원툴(J): 스팟힐링(자동), 힐링브러시(Alt 기준점), 패치, 콘텐츠인식이동, 적목현상
🔖 복제도장(S): Alt+클릭 기준점 > 드래그 복제 (선명복제) · 패턴도장: Edit>Define Pattern
✏️ 브러시(B): [ / ] 크기, Shift+[ ] 경도 · Opacity(불투명)/Flow(흐름)
🎨 브러시 세팅(F5): 쉐이프 다이내믹, 스캐터링, 듀얼브러시, 컬러 다이내믹, Transfer 등
🧽 지우개(E): 배경지우개(투명), 마술지우개(유사색 일괄)
G 그라디언트(선형/원형/방사) · K 페인트통 · Alt+Del 전경색, Ctrl+Del 배경색 채우기
🎚️ 04. 이미지 보정 COLOR·TONES
Ctrl+Shift+L Auto Tone Alt+Shift+Ctrl+L Auto Contrast Ctrl+Shift+B Auto Color
🌓 Levels (Ctrl+L) – 히스토그램 보정(Input/Output Levels)
📈 Curves (Ctrl+M) – S자 곡선 = 대비 극대화, 정밀보정
🌈 Hue/Saturation (Ctrl+U) – 색상/채도/명도, Vibrance(자연스러운 채도)
🎨 Color Balance (Ctrl+B) / Black & White (Alt+Shift+Ctrl+B) · Photo Filter
✨ 특수보정: Invert(Ctrl+I), Posterize, Gradient Map, Selective Color, Shadows/Highlights, Match Color, Replace Color
✅ 전체보정 = Levels, 부분/정밀 = Curves, 색감 = Hue/Saturation
✒️ 05. 드로잉+벡터+텍스트 PEN·SHAPE·TYPE
P 펜툴 : 직선/곡선 기준점, Alt 방향선 제거, Ctrl+Enter 패스→선택영역
자유변형 펜, 곡률펜, 콘텐츠인식 추적, 기준점 추가/삭제, 변환포인트
U Shape 툴 : 사각형/원/다각형, Fill/Stroke, Shift 비율유지, 레스터화(비트맵전환)
T 텍스트툴 : 가로/세로, 마스크 텍스트, Character패널(행간/자간), Warp Text 왜곡, 패스따라 글쓰기
📌 패스 따라 글씨: 패스 위에 텍스트툴 커서 → 클릭 입력
🌀 06. 합성의 정수 BLEND MODE · MASK · CHANNEL
모드효과
Multiply전체 어둡게 (흰색 투명)
Screen전체 밝게 (검정 투명)
Overlay대비 강조, 중간색 혼합
Soft Light / Hard Light부드러운/강한 조명효과
Color / Luminosity색상/명도 유지 합성
🧩 Opacity vs Fill: Fill=0% + 레이어스타일 → 이미지만 숨기고 효과 유지
✨ 레이어 스타일(fx): Drop Shadow, Inner Shadow, Bevel & Emboss, Stroke, Overlay
🎭 레이어 마스크: 흰색=보임, 검정=가림(비파괴). Alt+클릭 마스크 원본보기, Shift 비활성화
✂️ 클리핑 마스크: Ctrl+Alt+G (아래 레이어 형태로 위 레이어 제한)
⚡ 조정 레이어 – 원본 손상 없이 색상보정 (반원 아이콘)
📀 채널 패널: RGB/CMYK, 알파채널(선택영역 흑백 저장), Ctrl+클릭 선택영역 로드
✨ 07. 필터 & 스마트 필터 AI+LIQUIFY+GALLERY
🧠 스마트 필터: [Filter > Convert for Smart Filters] 비파괴적용, 수정가능
🤖 뉴럴 필터: Colorize(흑백→컬러), Landscape Mixer, Skin Smoothing, Smart Portrait, Harmonization
💧 Liquify (Shift+Ctrl+X) – Forward Warp, Pucker, Bloat, Face Tool 얼굴인식, Freeze Mask
🎨 필터 갤러리: Artistic, Sketch, Texture, Stylize 등 중첩가능
📌 주요 필터: Gaussian Blur, Motion Blur, Add Noise, Mosaic, Clouds, Lens Flare, Unsharp Mask, High Pass, Polar Coordinates, Wind, Emboss
⚡ High Pass + Overlay 모드 = 초고속 선명도 향상 기법!
🚀 08. 실무 테크닉 & 마스터팁
  • 🎯 마스크+클리핑마스크: 이미지가 텍스트에 채워진 효과
  • 🎯 Fill=0% + Inner Shadow → 조각 새김 효과
  • 🎯 그라디언트(검정→투명)+클리핑마스크 = 자연스러운 그림자
  • 🎯 Wind 필터 반복 적용 → 속도감/역동감
  • 🎯 High Pass + Overlay: 선명도 향상 (고급 샤픈)
  • 🎯 Displace 필터 + PSD 맵 → 텍스트 입체 질감
  • 🎯 Polar Coordinates → 방사형 배경
  • 🎯 Clouds + Difference Clouds + Filter Gallery → Grunge 텍스트
  • 🎯 [Select] > Modify > Contract 2px: 흰 테두리 제거
  • 🎯 Ctrl+F: 마지막 필터 재적용 / Alt+Ctrl+F 수치변경 재적용
  • 🎯 Image > Apply Image: 채널/레이어 합성 → 정교한 마스크
💎 듀얼브러시 + Spacing 200% = 1x1x1 반복 패턴 아트
